# Customer Behavior & Shopping Trends Analysis

## Project Overview

This project analyzes customer shopping behavior using transactional
retail data to uncover patterns in spending, customer segments, product
preferences, discount usage, shipping behavior, and subscription status.

The project demonstrates an end-to-end data analytics workflow:

**Raw Data → Python Data Preparation → PostgreSQL → SQL Analysis → Power
BI Dashboard → Business Recommendations**

The goal is to show how raw customer data can be transformed into
structured analysis and business-facing insights.

------------------------------------------------------------------------

## Business Questions

The analysis answers the following business questions:

1.  What is the total revenue generated by male vs. female customers?
2.  Which customers used a discount but still spent more than the
    average purchase amount?
3.  Which five products have the highest average review rating?
4.  How does average purchase amount compare between Standard and
    Express shipping?
5.  Do subscribed customers spend more than non-subscribers?
6.  Which five products have the highest percentage of purchases with
    discounts applied?
7.  How can customers be segmented into New, Returning, and Loyal
    customers based on previous purchases?
8.  What are the top three most purchased products within each category?
9.  Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

## Data Preparation with Python

Python and Pandas were used to inspect, clean, and prepare the dataset
before loading it into PostgreSQL.

### Data preparation steps

-   Loaded the CSV dataset with Pandas
-   Inspected dataset structure with `info()`
-   Reviewed descriptive statistics
-   Checked for missing values
-   Imputed missing review ratings using the median rating of each
    product category
-   Standardized column names to snake_case
-   Renamed the purchase amount field for easier SQL usage
-   Created an `age_group` feature using age quartiles
-   Converted purchase-frequency labels into a numeric
    `purchase_frequency_days` field
-   Checked for redundant discount/promo fields
-   Removed the redundant `promo_code_used` field
-   Loaded the cleaned DataFrame into PostgreSQL

## SQL Analysis

PostgreSQL was used to answer the business questions and demonstrate
analytical SQL techniques.

The analysis includes:

-   Aggregations with `SUM()`, `AVG()`, and `COUNT()`
-   `GROUP BY`
-   Filtering with `WHERE`
-   Conditional logic with `CASE`
-   Subqueries
-   Common Table Expressions (CTEs)
-   Window functions with `ROW_NUMBER()`
-   Ranking
-   Percentage calculations
-   Customer segmentation
-   Comparative analysis

### Example: Customer Segmentation

Customers were segmented based on their number of previous purchases:

``` sql
WITH customer_type AS (
    SELECT
        customer_id,
        previous_purchases,
        CASE
            WHEN previous_purchases = 1 THEN 'New'
            WHEN previous_purchases BETWEEN 2 AND 10 THEN 'Returning'
            ELSE 'Loyal'
        END AS customer_segment
    FROM customer
)
SELECT
    customer_segment,
    COUNT(*) AS number_of_customers
FROM customer_type
GROUP BY customer_segment;
```

### Example: Top Products Within Each Category

A window function was used to rank products within each category:

``` sql
WITH item_counts AS (
    SELECT
        category,
        item_purchased,
        COUNT(customer_id) AS total_orders,
        ROW_NUMBER() OVER (
            PARTITION BY category
            ORDER BY COUNT(customer_id) DESC
        ) AS item_rank
    FROM customer
    GROUP BY category, item_purchased
)
SELECT
    item_rank,
    category,
    item_purchased,
    total_orders
FROM item_counts
WHERE item_rank <= 3;
```

## Business Recommendations

Based on the analysis, several potential business actions were
identified:

-   **Strengthen subscription value:** Subscriber spending was not
    higher in this dataset, suggesting that subscription benefits and
    value propositions could be reviewed.
-   **Develop loyalty strategies:** The dataset contains a large Loyal
    segment, creating an opportunity to study retention and loyalty
    behavior more deeply.
-   **Review discount strategy:** Products with high discount usage
    could be monitored to understand whether discounts are driving
    purchases effectively.
-   **Use product performance in campaigns:** Highly rated and
    frequently purchased products may be useful candidates for
    promotional campaigns.
-   **Explore customer targeting:** Differences in revenue contribution
    across age groups can inform future segmentation and marketing
    analysis.

These recommendations are exploratory and based on the available
dataset; they should not be interpreted as causal conclusions.
